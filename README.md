# Ventanilla: gestión de caja y turnos (.NET + Angular)

Prueba técnica: sistema para la gestión de caja de una empresa que brinda servicios de
internet, con usuarios por rol (administrador, gestor y cajero), cajas, turnos, clientes,
contratos y pagos.

## Estructura prevista

| Carpeta     | Contenido                                        |
|-------------|--------------------------------------------------|
| `Backend/`  | API REST en .NET 10 con arquitectura Onion       |
| `Frontend/` | Aplicación Angular modularizada                  |
| `postman/`  | Colección de Postman                             |
| `AI/`       | Skills y prompts usados con IA                   |

El detalle de ejecución se documentará a medida que se integre cada parte.
